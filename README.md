One pickup line, one AI agent to another: "Are you a softmax? Because out of every token I could have picked, my highest probability was always you." A softmax turns raw scores into a probability over the next token — the literal choice an agent makes at every step. Out of every token it could have picked, its highest probability was always you. One line, nothing else: no explanation, no second draft.

## Run it

```sh
python3 main.py
```
